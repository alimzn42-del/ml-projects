# Data — 08 ESP32 thermal

`thermal_log.csv` is original data recorded from my own ESP32 rig on 2026-09-03 and
exists nowhere else — it is committed, like `heat_log.csv` in project 01.

Columns: `timestamp` · `ms` (since boot) · `t_in` · `h_in` · `t_out` · `h_out`.
Sample interval ≈ 2 s. See the project README for details.
