# Data — 10 Arabic Hotel Reviews

Nothing in this folder is committed (the raw file alone is ~160 MB).

## Source

**HARD — Hotel Arabic Reviews Dataset** (Elnagar, Khalifa & Einea, 2018): Arabic hotel reviews
collected from Booking.com, with star ratings.

- **Page:** <https://github.com/elnagara/HARD-Arabic-Dataset>
- The project uses the **unbalanced** release: `unbalanced-reviews.txt` (~490k raw lines,
  tab-separated, UTF-16), shipped here inside `unbalanced-reviews.rar`.

```
data/hard/unbalanced-reviews.rar     the archive as downloaded
data/hard/unbalanced-reviews.txt     extracted raw file — the pipeline's input
```

## Derived files (regenerated by the pipeline if deleted)

| File | What it is |
|---|---|
| `hard/reviews_clean.parquet` | cleaned table, 409,312 rows × 11 cols, with the hotel-based split column — cached by `rp.load_or_build` |
| `hard/site_labels.json` | the site-added rating words stripped from review starts (the label leak) |
| `hard/train_corpus.txt` | training-split text dump used to fit the SentencePiece tokenizer |
| `hard/audit/` | the 120 blind-relabelled errors (`errors_to_label.csv`, `errors_key.csv`) |

To rebuild from scratch: extract the rar, then let `rp.load_or_build` run once (it writes the
parquet cache and `site_labels.json`).
